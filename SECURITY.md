# Pelaporan keamanan

Masalah keamanan sebaiknya dilaporkan secara privat agar detail dan cara eksploitasi tidak langsung terlihat publik.

Jika fitur **Private vulnerability reporting** tersedia pada halaman Security repository, gunakan fitur tersebut. Jika tidak tersedia, hubungi maintainer melalui [profil GitHub](https://github.com/ekiguistian) dan hindari membuka issue publik yang berisi detail kerentanan.

Jangan sertakan API key, token webhook, `.env`, log yang memuat data sensitif, atau payload pengguna dalam laporan. Rahasia yang terlanjur dipublikasikan perlu dicabut dan diganti.
